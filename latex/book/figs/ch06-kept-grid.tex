\caption{The set $\Psi(A_0)$ of characters of $\GG=V_4\times H$ trivial
on $0\times A_0$, drawn for $o=[H:A_0]=3$. Since $\GG/(0\times
A_0)\cong V_4\times H/A_0$, each such $\theta$ is a character of $V_4$
(row) times a character $\psi$ of $H/A_0$ (column), so
$|\Psi(A_0)|=4o$. The value $\theta(s_0)$ depends only on the row, and
the character conditions (Definition~\ref{def:kept-chars}) put only
characters with $\theta(s_0)=1$ in the kept set $\Xi$. The weight
$\wt_A(\theta)$ is $1$ in the column $\psi=1$ and $\varkappa$ elsewhere.
Every character of $\Psi(A_0)$ not in $\Xi$ enters the rest
$\Sigma_A$. For a host, $\omega\in\Xi$ exactly when the level has an
exceptional character, and which of the other light cells lie in $\Xi$
is fixed by $\Kept(\lev)$ (Theorem~\ref{thm:averaged-hyps}).}
