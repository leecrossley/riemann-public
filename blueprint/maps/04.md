## Hollow or trivial items

- `ArithData` carries no axioms. In particular the inertness of a prime depends only on the arbitrary
  `frob` field. `cftData` defines `frob p` through `frobUnit`, which takes the junk value 1 if no unit
  exists. For a prime p, CRT always provides such a unit, so the junk branch looks unreachable for
  primes. This was not checked in Lean.
- `ell` is arbitrary in the balance identity and in ch_core. It is tied to L'/L(1, chi) only through
  `HostAddCharCompatible` in the host part.
