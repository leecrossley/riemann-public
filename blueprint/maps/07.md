## Survey versus Lean

- Question `q:continuous` of the survey is answered: `ReciprocityTheory.Gal.Z1`
  (`ReciprocityTheory/GaloisValuations/SeparatedDvrSecondCohomologyMem.lean:42`) requires
  continuous cocycles, and `QZ l` has the discrete topology. So `Sha` is continuous
  cohomology.
- The survey's `LemmaK` (archconj `conj:lemmaK`) bundles two different archive statements.
  The archive's `UpperTheory.V.LemmaK` is only part (b), the doubly exponential bound
  `log|H^2| <= (2|d_L|)^((2e[L:Q])^CK)`. Part (a) is the separate statement
  `KatoTwoW` (and `U3.KatoUse`).
- `CountV` is Case V **with** `R1 l psi <= 2^(c2 psi)`; `CountVs` is the complementary
  sub-case. The survey's summary `sum:counts` lists `CountV` as plain Case V.
- `CountIV` is an archive theorem with no hypotheses (`UpperTheory.V.HV.countIV : CountIV`);
  its statement contains the layer budget `B` as an input. `PropZ` is also proved
  outright (`UpperTheory.V.X.propZ`), so `CountZ` is unconditional on the main chain.
- `Ferrero--Washington` in the archive's form (bounded `l`-rank of class groups up a
  cyclotomic tower) is proved by an in-archive term `UpperTheory.V.FW.ferreroWashington`;
  the survey treats it as an input. Its proof was read only at the top; it is short
  for a theorem of this size and should be audited.
- The survey's description of `NumberU3U_s` ("product of differences") is right up to two
  details: the trace is at `sigma^{-1}`, and the statement is an inequality
  `||N||_l <= prod ||tr - eis3||_l`, not an equality.
- `sumIn` does not use `redPrime` (which needs `l` prime to the index of `H`); it uses
  `redAll` with a loss term. The survey does not mention this.
- Survey Definition `def:cases` agrees with the Lean (`CaseI`..`CaseV`, `chiP`,
  `proj`); the survey's warning about the CRT projection is correct.

## Misleading names (remarks in the chapter)

- `VWin`: not analytic; a Sha bound.
- `BoundedHeightTwoPlaceCondition`: the 2-part Sha budget, nothing about heights.
- `SymplecticFourImageDense`: finiteness + no-endpoint + automorphy of all irreducible
  points of the GSp4 data; no image-density statement.
- `OpenImageCondition`: a one-field record containing `RowT` (= `Row0b` for `IsRecT`).
  All `*_of_open O` lemmas ignore `O`.
- "U3": the statements use `GG 3` (GL3 semidirect {±1}) and conjugate self-dual automorphy;
  no unitary group appears in `PropGK`.

## Hollow / degenerate points checked

- `PropGK` for `K` not imaginary quadratic: proof takes `NN = 1`, `c5 = A = 0`, because
  `GD` is unsatisfiable (`FPropGKU.lean:113-117`). Harmless.
- `Vlen` local conditions: `shaFam` uses `Ine A` for every valuation subring `A` of
  `Omega`, including the trivial one `A = Omega`. Checked: `Ine Omega` is trivial (the
  inertia condition forces `sigma = id`), so the condition is the usual "unramified
  everywhere", not a hollow kill-everything condition.
- `nrm` / `shaLen.toNat` send infinity to 0, but every budget also asserts finiteness
  separately, so the junk value is not exploitable.
- `orb c H'` can be empty; then the sum is 0, which is consistent.
